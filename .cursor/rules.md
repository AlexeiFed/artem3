# Project rules

Read this index before every task, then load every rule whose glob matches the files being changed.

- `rules/core-architecture.mdc` — always-on architecture and scope.
- `rules/design-system.mdc` — UI, CSS, Motion and design tokens.
- `rules/typescript-api-security.mdc` — TypeScript, API boundaries and secrets.
- `rules/database.mdc` — Drizzle schema, repositories and migrations.
- `rules/testing-verification.mdc` — TDD and required verification.

Rules are mandatory. If they conflict with a task specification, stop and request clarification.
