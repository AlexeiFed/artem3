Боевой деплой теперь такой:

Команда
./deploy.sh


Что делает
Собирает локально с NEXT_PUBLIC_SITE_URL=https://vibespace27.ru
Заливает в новый каталог /var/www/vibespace-releases/<timestamp> — живой сайт не трогает
БД: не дропает. Только CREATE если нет + db:migrate (пустой no-op, если миграций нет)
Seed — только если БД пустая / FORCE_SEED=1
Поднимает probe на :3011, ждёт HTTP 200
Только после успеха: symlink /var/www/vibespace → релиз, переключает PM2 :3001
При фейле probe — старый PM2 остаётся, сайт живёт
Uploads лежат в /var/www/vibespace-shared/..., между релизами не теряются.

Опасные флаги (только если надо)
RESET_DB=1 ./deploy.sh   # снести БД и пересоздать
FORCE_SEED=1 ./deploy.sh # досеять пустые таблицы
На успешном switch будет короткий блинк (~1–2 с) — это нормально. Из‑за неудачного деплоя сайт больше не должен падать.
