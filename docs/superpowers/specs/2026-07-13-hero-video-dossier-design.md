# Hero с видеопортретом и «досье результата»

## Цель

Первый экран должен полностью помещать ключевой контент при первом открытии сайта, быстро объяснять специализацию Артёма, создавать личное доверие и вести к заявке.

Утверждённая концепция:

- локальный немой видеопортрет Артёма занимает весь фон hero;
- оффер расположен слева в безопасной тёмной зоне видео;
- показатели оформлены как асимметричный лист «Практика в цифрах», входящий в сцену справа;
- лист закрывает знак ИИ в правом нижнем углу исходного видео;
- интервью с клиентом не используется в hero и остаётся кандидатом для отдельного блока доверия.

## Контент

### Заголовок

Доступное имя `h1`:

> Развод, алименты и раздел имущества в Хабаровске

На desktop заголовок принудительно разбивается на три смысловые строки:

1. `Развод, алименты`
2. `и раздел имущества`
3. `в Хабаровске`

Предлог `в` не отделяется от `Хабаровске`. Третья строка получает курсивное начертание и светлый шалфейный оттенок.

### Подзаголовок и действие

Подзаголовок:

> Помогаю решить семейные и имущественные споры без лишнего стресса и затяжных судов.

CTA использует существующий modal flow и получает точную подпись:

> Получить оценку ситуации

Под кнопкой всегда виден текст:

> Первая консультация — бесплатная.

Существующее поле `disclaimer` получает точный текст:

> Первая консультация — бесплатная. Результат по делу заранее не гарантируется.

### Показатели

Лист содержит ровно три показателя:

- `11+` — `лет практики`;
- `200+` — `дел доведено до результата`;
- `0 ₽` — `первая консультация`.

Показатели должны приходить из `LandingData`, а не быть захардкожены в компоненте. Для hero добавляется типизированное поле `metrics` из трёх элементов `{ value, label }`. Zod-схема подставляет утверждённые три значения по умолчанию для ранее сохранённых hero-настроек без `metrics`; поэтому существующие JSON-данные не ломают публичный API. При следующем сохранении из админки значения записываются явно.

Существующие `badges` сохраняются в контракте до отдельного решения об их удалении, но в hero не отображаются.

## Видео

Исходник: `/Users/alex/Downloads/artem.mp4`.

Исходные параметры:

- 1280×720;
- H.264, 24 fps;
- 10 секунд;
- исходный размер около 2,45 МБ;
- звуковая дорожка не используется.

### Подготовка цикла

Первый кадр относится к другой композиции и не может использоваться. Финальная версия:

- удаляет первые `0,75 с`;
- сводит последние `0,5 с` с подходящим фрагментом начала через crossfade;
- начинается и заканчивается на визуально совместимом положении Артёма;
- не содержит аудиодорожку;
- имеет `faststart`.

Проверенный прототип имеет длительность `9,25 с` и размер около `1,45 МБ`.

Production-файл размещается как `/public/media/artem-hero-loop.mp4`. Из подходящего кадра создаётся `/public/media/artem-hero-poster.jpg`.

### Поведение

Видео использует:

- `autoplay`;
- `muted`;
- `loop`;
- `playsInline`;
- `preload="metadata"`;
- оптимизированный `poster`.

Звуковая кнопка удаляется: ролик предназначен только для беззвучного фонового воспроизведения.

При ошибке загрузки остаётся poster без пустого или мигающего фона. При `prefers-reduced-motion: reduce` видео не запускается, а hero показывает poster.

## Композиция

### Header

Header располагается поверх видео без нижней разделительной линии. Для читаемости разрешён только мягкий вертикальный градиент из существующих токенов.

### Текст

Desktop:

- hero `h1`: `clamp(3.25rem, 6.4vw, 6rem)` — 52–96 px;
- заголовки остальных секций: 44–80 px;
- hero остаётся примерно на 20% крупнее следующего уровня;
- ширина текстовой колонки позволяет сохранить утверждённые три строки.

Mobile:

- hero `h1`: 40–56 px;
- переносы становятся адаптивными, но `в Хабаровске` остаётся неделимой смысловой строкой;
- оффер, CTA, бесплатная консультация и показатели помещаются в `100svh` на целевых экранах от 390×844.

Основной цвет заголовка — `background` из дизайн-токенов, не чистый белый. География использует `color-mix` только из `background` и `accentSage`.

### Затемнение видео

Слева используется градиент из `textPrimary` и `accentForest`, обеспечивающий контраст текста. Лицо и руки Артёма не затемняются сплошной плашкой.

### Лист «Практика в цифрах»

Лист:

- входит справа и касается правой границы viewport;
- имеет левое скругление из `radius.panel`, но не выглядит стандартной центрированной карточкой;
- содержит вкладку `Практика в цифрах`;
- маркирует показатели индексами `01`, `02`, `03`;
- использует фон с непрозрачностью около 88%;
- ячейка `0 ₽` использует непрозрачность около 96%, чтобы полностью скрыть знак ИИ;
- не использует `backdrop-filter`;
- сохраняет читаемость поверх всех кадров видео.

На mobile лист занимает ширину hero с безопасными боковыми отступами и остаётся трёхколоночным. Подписи допускают две строки.

## Анимация

Последовательность первого появления:

1. зелёная «обложка дела» раскрывает видео справа налево;
2. eyebrow и три строки заголовка проявляются последовательно;
3. CTA и текст бесплатной консультации появляются без смещения layout;
4. линия листа раскрывается слева направо;
5. лист входит справа, затем показатели появляются `01 → 02 → 03`.

Используется `motion/react`, только `transform`, `opacity` и `clip-path`. Анимация короткая и выполняется один раз. При reduced motion весь контент показывается сразу.

## Адаптивность и безопасные зоны

- Desktop video: `object-fit: cover`, лицо сохраняется в правой трети.
- Mobile: отдельное `object-position` удерживает лицо в кадре, текст получает более плотный градиент.
- Header не пересекает лицо линиями или декоративными элементами.
- Лист не закрывает лицо; перекрытие рук и документов допустимо.
- Не допускаются горизонтальный overflow и обрезание CTA.

## Доступность

- `h1` сохраняет единое доступное имя независимо от визуальных строк.
- Фоновое видео исключено из accessibility tree.
- Вся информация из видео продублирована текстом.
- CTA остаётся нативной кнопкой с видимым focus state.
- Poster обеспечивает стабильный первый кадр.
- Контраст текста и панели проверяется для каждого состояния видео.

## Ошибки и fallback

- Ошибка видео не скрывает hero-контент.
- До готовности видео показывается poster без скачка layout.
- При отсутствии poster используется существующий абстрактный фон из дизайн-токенов.
- Данные `metrics` валидируются Zod как ровно три непустых значения.

## Проверка

### Компонентные тесты

- точное доступное имя `h1`;
- CTA открывает существующую форму;
- виден текст `Первая консультация — бесплатная.`;
- отображаются `11+`, `200+`, `0 ₽` и подписи;
- video получает `muted`, `loop`, `playsInline`, poster и локальный source;
- старый VK iframe и звуковая кнопка не рендерятся для локального hero-видео;
- reduced motion оставляет poster.

### Визуальные и браузерные проверки

- 1366×768 и 1440×900: весь обязательный контент находится в первом viewport;
- 390×844 и 393×852: нет горизонтального overflow, CTA и показатели видимы;
- header не пересекает лицо;
- панель полностью скрывает знак ИИ на протяжении всего ролика;
- переход конца в начало не воспринимается как смена сцены;
- poster и video не вызывают layout shift.

### Финальная проверка

Перед передачей выполнить:

- focused component tests;
- `npm test`;
- `npm run typecheck`;
- `npm run lint`;
- `npm run build`;
- `npm run test:e2e`;
- ручную проверку reduced motion и autoplay в Safari и Chrome на macOS.

## Вне текущего объёма

- монтаж или публикация интервью с клиентом;
- создание отдельного блока доверия;
- удаление существующих `badges` из публичного контракта;
- изменение остальных секций лендинга.
